# MicroDuck 工作台前后端

## Windows 实机工作台

在已配置的 Windows 电脑上双击 [启动实机工作台.cmd](启动实机工作台.cmd)，浏览器会打开 [实机工作台](http://127.0.0.1:8770/)。小鸭与电脑需要在同一网络，电脑使用现有 OpenSSH 配置连接主板。等待页面显示「已确认全部卸力」和 15 路实际关节角度。需要确认关节姿态时，打开 [关节对照台](http://127.0.0.1:8766/)。

1. 现场准备小鸭并留出关节活动空间。在工作台选择「地面起身」或「动态站立」，勾选页面中对应的准备确认，再点击启动。
2. 等待动态平衡稳定。现场确认小鸭能独立站稳后，勾选确认并解锁移动。按住前进／后退，或按住 `W`／`S`。松开或按空格停步，保持平衡。
3. 结束时先托稳躯干，再点「停止并卸力」或按 `Esc`。等待页面读回全部卸力，再离开或关机。
4. 已卸力时可以读取静态 IMU。「本次记录」可下载本轮 JSON。控制器日志和遥测保存在 `.local/workbench-live/runtime/outputs/workbench/`。

Windows 启动入口使用 `.local/workbench-live/` 下的 Python 3.12 环境和运行副本。运行副本包含包内 `walking-runtime/`、`local-joint-viewer/` 和 `official-microduck-rl/`，以及从现行板端回读的部署清单、软件零位、关节限位、运行合同、站姿参考和 IMU 证书。连接参数保存在运行副本内的 `walking-runtime/workbench-config.json`。更换板子或更新标定时，同步更新这些成套文件，再启动工作台。Windows 关节对照台的依赖见 [requirements-viewer.txt](local-joint-viewer/requirements-viewer.txt)。

要用语音触发起身和前进，确认已卸力后双击 [启动语音起身前进.cmd](启动语音起身前进.cmd)。该入口暂时让出关节采集，退出时自动恢复。 [两条语音指令的操作步骤](../docs/多轮语音对话.md#语音起身后前进)

## 解压后先试用

只看页面时，打开 [纯前端演示](纯前端演示/打开离线演示.html)。要验证页面和后端一起运行，在解压目录里用 Python 3.9 或更新版本执行：

```sh
python3 walking-runtime/workbench_server.py --simulation
```

浏览器打开 [http://127.0.0.1:8770/](http://127.0.0.1:8770/)。如果本机已有工作台占用端口，在命令末尾加 `--port 8870`，浏览器改用 8870。关闭终端里的服务可以按 Ctrl+C。

模拟模式使用同一个前端和 HTTP 接口。站立、起身、移动、关节数据和导出可在浏览器里体验，所有读数和动作都是模拟。前端在 [walking-runtime/workbench.html](walking-runtime/workbench.html)，HTTP 服务在 [walking-runtime/workbench_server.py](walking-runtime/workbench_server.py)。实机控制由 `manual_stance_panel.py`、`manual_walk_panel.py` 和板端 Python 桥接提供。

## 在自己的小鸭子上运行

适配对象是 Radxa Zero 3W（ARM64 Linux）、15 个 XL330 舵机和接入 TTL 总线的 ID 200 IMU，板端串口为 `/dev/ttyS2`，总线速率 1 Mbps。主板应已能通过 SSH 登录，并已完成串口和硬件设置。接收方使用自己实测的 15 关节软件零位和 IMU 安装四元数。包内 Rust 运行时为 `daemon-v0.17.9` 的原生 HOME 定制版，12 号 +30.24°，22 号 −30.24°，对应的源码和补丁也在包内。

1. 在 Mac 的解压目录创建 `device-access/`，放入自己的 SSH 私钥 `id_ed25519_board`（权限 600）和核对过指纹的 `known_hosts`。主板上的 root 账户应已授权对应公钥。
2. 用已校准的 `software-zero-reference.json` 和实测 IMU 安装四元数生成本机和板端配置。下面的尖括号参数按自己的机器替换，四元数顺序为 `W X Y Z`。

   ```sh
   python3 配置实机.py <板子IPv4地址> --profile <标定文件路径> --imu-mount <W> <X> <Y> <Z>
   ```

3. 把生成配置后的解压目录中的 `walking-runtime/`、`local-joint-viewer/`、`mumu-duck/`、`board-assets/` 四个目录复制到板端同一个临时目录。SSH 材料留在 Mac。首次安装时先托稳小鸭、确认舵机卸力、退出旧的控制和采集程序，再以 root 执行 `sh board-assets/安装板端文件.sh`。已有部署时，使用现有安装流程备份和核对版本，再切换桥接和原生程序。
4. Mac 端用 Python 3.12 或更新版本准备关节采集依赖。用自己的板子地址代入下面的命令。关节页在 8766，确认 15 个关节读数在线、全部卸力后，再跟随 8768 的页面做四步 IMU 方向核对，完成后点击「结束只读核对并恢复关节页面」。

   ```sh
   python3 -m venv local-joint-viewer/.venv
   local-joint-viewer/.venv/bin/python -m pip install -r local-joint-viewer/requirements-viewer.txt
   python3 walking-runtime/launch_workbench.py --no-open
   python3 walking-runtime/imu_direction_panel.py --host <板子IPv4地址> --output-dir outputs/imu-direction
   ```

5. 打开 [工作台](http://127.0.0.1:8770/)，等候关节遥测和标定检查通过。参数、校准和运行时哈希检查正常后，页面会开放开始按钮。
